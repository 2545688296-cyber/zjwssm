# 厨房练习簿 · zjwssm

一个给自己学做菜用的小程序原型。它的目标不是收藏教程，而是记录你每次真实下厨的过程、判断和复盘，然后在以后买菜后根据现有食材推荐你做过的菜。

这是你的个人站点版本，站点标识是 `zjwssm`。

## 怎么打开

当前目录已经可以直接通过本地服务器访问：

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

然后打开：

```text
http://127.0.0.1:4173/
```

如果用的是 Codex 自带的 Python，可以使用：

```powershell
& 'C:\Users\ZhuanZ（无密码）\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' -m http.server 4173 --bind 127.0.0.1
```

## 现在能做什么

- 记录一道菜的菜名、来源、评分、难度、日期、用时、份量和第几次做。
- 记录食材、调味料、工具、准备过程、下锅步骤、火候时间、试吃感受、翻车点、下次要改、真正学到的经验。
- 搜索自己做过的菜，支持按菜名、食材、调味料、标签和经验关键词搜索。
- 输入今天手头的食材，自动推荐做过的菜，并显示匹配了什么、可能还缺什么。
- 自动整理最近应该复做的菜、高分菜、最近学到的东西和常用食材。
- 记录页分成速记区和折叠细节区，做完饭很累时可以先保存最重要的信息。
- 推荐页提供常用食材快捷按钮，并把抽象分数改成“现在就能做 / 补一点就能做 / 只匹配到一部分”。
- 复盘页会自动给出下一次建议复做的菜。
- 支持给每道菜上传照片，并在复盘页和开场页展示缩略图。
- 进入网站前有一个互动开场，可以先看几道菜的概览。
- 导出 JSON、复制 JSON、导入 JSON，方便以后备份或迁移。

## 推荐规则

推荐不是从网上找新菜，而是从你自己的记录里找菜。排序会参考：

- 输入食材和菜谱食材、调味料的匹配数量。
- 你给这道菜的评分。
- 你做过这道菜的次数。
- 难度是否适合快速开做。
- 这道菜是否已经写过步骤和下次提醒。

所以它会更偏向推荐你真正练过、成功率更高、现在材料更接近的菜。

## 为什么这样设计

你遇到的问题不是“教程不够多”，而是“做完以后经验没有沉淀”。所以这个原型把记录拆成几个学习节点：

- 准备过程：训练切配、腌制、焯水这些前置判断。
- 下锅步骤：把教程动作改写成自己的语言。
- 火候时间：记录最容易忘的关键控制。
- 试吃感受：把结果和过程连起来。
- 翻车点：把失败变成下次能避免的具体事项。
- 真正学到什么：用一句自己的话提炼经验。

## 后续迁移到微信小程序

第一版可以先继续用网页验证需求。等你记录了 10 到 20 道菜后，再迁移会更稳。

建议迁移路线：

1. 页面拆成微信小程序的 `pages/index`、`pages/record`、`pages/recommend`、`pages/review`。
2. 当前 JSON 数据结构基本可以直接变成云数据库里的 `recipes` 集合。
3. 本地 `localStorage` 替换成 `wx.getStorageSync` / `wx.setStorageSync`。
4. 如果要多设备同步，再接微信云开发数据库。
5. 后续可以加拍照、语音记录、食材保质期、复做提醒。
